# M7 acceptance

Every local check is optional. Remote CI or the platform pipeline is the only hard gate.

Reproduce every row with `go run ./tools/acceptance -m7` from a checkout of the kit. Each row runs under a home of its own below the temporary directory of the run and adopts the synthetic fixture of tools/acceptance/testdata/gen, which names no company, or a tree the row writes itself. No row runs an agent or reads a real configuration directory. The preparation builds the candidate behind a local module proxy and builds the pinned generators once with golaw setup --gen into a data home of the run, which reaches the public module proxy; a row that needs them reports SKIP, required, with the cause when they could not be built. The two rows that run make ci over the fresh repository also need the M6 surface tools and redocly on PATH, which the generated CI installs with npm (this run used @redocly/cli 2.5.0), and report SKIP, required, with the cause when either is absent. The release run, `go run ./tools/acceptance -release`, requires the same rows.
