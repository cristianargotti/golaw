# M6 acceptance

Every local check is optional. Remote CI or the platform pipeline is the only hard gate.

Reproduce every row with `go run ./tools/acceptance -m6` from a checkout of the kit. Each row runs under a home of its own below the temporary directory of the run and adopts a synthetic fixture with no company name: the twins of internal/surfacefix, the coverage module and the denial and configuration fixtures of tools/acceptance/testdata/m6. No row runs an agent or reads a real configuration directory. The preparation builds the candidate behind a local module proxy, fills the module cache from the public module proxy when it is cold, and installs the surface tools once with golaw setup --surface=all into a data home of the run, which reaches GitHub, npm and PyPI; a row that needs those tools reports SKIP, required, with the cause when they could not be installed. The release run, `go run ./tools/acceptance -release`, requires the same rows.

The rows ran over the candidate built from revision ce19b9b3829f50dc5bfbaddd7cd3829c8c9e48cd, with a clean tree. The candidate's module holds this record, so the commit that records the digest, and every later commit, builds another digest; this evidence applies only to the binary named here.

Linux and Windows rows count only from a native run, never from macOS or a cross build. SKIP never counts as PASS. The kit carries no native job for these rows yet, so their Linux and Windows cells stay not run until one exists.

On this run golaw setup --surface=all installed every pinned tool. The installation runs on the prerequisite PATH of the harness, which carries only go, git, sh and the candidate, plus the first directory of the caller's PATH whose node and whose python3 answer within the bounds of the toolchain table, so a version manager shim or an older system Python ahead of a usable runtime is passed over; the rows that run the tools use the same two directories. A machine whose PATH holds no runtime within those bounds records the four rows that need the whole tool set as SKIP with that cause, which counts as no evidence.

Row 8 of the milestone, the workspace harness that runs both twins through a local analyzer server with the pipeline's properties and records the gate and the count of every exact row of the rule map, lives outside the public kit and is recorded by its owner; no row of this record claims it.
