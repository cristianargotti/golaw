# 4. a TOML decoder for the gitleaks and squawk files

## Context

`policy.gitleaks-generic` reads `.gitleaks.toml`, whose rules and allowlists carry regular expressions, often as multi-line literal strings, and `policy.squawk-config` reads `.squawk.toml`. The standard library has no TOML decoder. A reader of a declared subset would make a valid configuration a stated limit, and a stated limit fails the pipeline, which the owner's zero friction goal forbids for a file the tool itself accepts.

## Decision

Use `github.com/BurntSushi/toml`, which has no dependency, at an exact pinned version, inside `internal/checks/policyfiles` only, decoding each file whole through the snapshot.

## Consequences

One module enters the binary. The version enters seven days after publication. A syntax error names the file and the line the decoder reports, and leaves the check unmeasured, never clean.
