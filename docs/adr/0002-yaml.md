# 2. yaml for the configuration and the manifests

## Context

`golaw.yml`, the proof manifest, the template manifest and the profile bundle are YAML. The standard library has no YAML decoder, and the policy must refuse an unknown key and a duplicate key, which needs a decoder with strict field matching.

## Decision

Use `gopkg.in/yaml.v3` with `KnownFields(true)` on every decoder. It is the decoder the delivery precedent already uses, so one YAML dialect governs every file the kit reads; the decoder refuses a duplicate mapping key by itself.

## Consequences

One module enters the binary. The version is pinned exactly and enters seven days after publication. Every value check beyond the shape (floors that only tighten, sets that only shrink) stays the policy package's job.
